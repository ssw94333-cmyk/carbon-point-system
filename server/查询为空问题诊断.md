# 查询为空问题诊断

## 问题描述

从日志中看到：
```
userId: 1, behaviorType: null, auditStatus: null, pageNum: 1, pageSize: 10
==>  Preparing: SELECT COUNT(*) AS total FROM carbon_behavior_record cbr WHERE 1 = 1 AND cbr.user_id = ?
==> Parameters: 1(Long)
<==      Total: 1
查询结果 - 总记录数: 0, 当前页记录数: 0
```

## 根本原因

**用户ID为1的用户（admin管理员）没有行为记录！**

数据库查询结果：
```
+----+---------+-----------------+--------------+---------------------+
| id | user_id | behavior_name   | audit_status | create_time         |
+----+---------+-----------------+--------------+---------------------+
| 16 |       8 | 无纸化办公      |            1 | 2026-01-17 13:56:26 |
| 15 |       8 | 公交出行        |            1 | 2026-01-17 13:56:10 |
| 14 |       9 | 公交出行        |            1 | 2026-01-17 13:09:34 |
| 12 |       8 | 步行出行        |            2 | 2026-01-14 19:32:32 |
| 11 |       8 | 步行出行        |            1 | 2026-01-14 19:14:56 |
| 10 |       7 | 步行出行        |            1 | 2026-01-14 17:03:05 |
+----+---------+-----------------+--------------+---------------------+
```

用户表：
```
+----+----------+-----------+
| id | username | user_type |
+----+----------+-----------+
|  1 | admin    |         1 |  <- 管理员，没有行为记录
|  2 | zhangsan |         0 |
|  8 | admin1   |         0 |  <- 有行为记录
|  9 | 1        |         0 |  <- 有行为记录
+----+----------+-----------+
```

## SQL检查

### 1. 检查用户的行为记录

```sql
-- 查看指定用户的记录
SELECT * FROM carbon_behavior_record WHERE user_id = 1;

-- 查看所有用户的记录统计
SELECT user_id, COUNT(*) as count 
FROM carbon_behavior_record 
GROUP BY user_id;
```

### 2. 检查分页查询SQL

从日志中看到的SQL是正确的：
```sql
SELECT COUNT(*) AS total 
FROM carbon_behavior_record cbr 
WHERE 1 = 1 AND cbr.user_id = ?
```

问题不在SQL，而是数据库中确实没有该用户的记录。

## 验证数据

### 查看user_id=8的记录

```sql
SELECT 
    cbr.id,
    cbr.user_id,
    u.username,
    cbr.behavior_name,
    cbr.behavior_value,
    cbr.carbon_reduction,
    cbr.points,
    cbr.audit_status,
    CASE cbr.audit_status
        WHEN 0 THEN '待审核'
        WHEN 1 THEN '审核通过'
        WHEN 2 THEN '审核拒绝'
    END AS audit_status_text,
    cbr.create_time
FROM carbon_behavior_record cbr
LEFT JOIN user u ON cbr.user_id = u.id
WHERE cbr.user_id = 8
ORDER BY cbr.create_time DESC;
```

### 查看统计数据

```sql
-- 各类行为统计
SELECT 
    cbr.behavior_type,
    cbr.behavior_name,
    br.unit,
    COUNT(*) AS count,
    SUM(cbr.behavior_value) AS totalValue,
    SUM(cbr.carbon_reduction) AS totalCarbon,
    SUM(cbr.points) AS totalPoints
FROM carbon_behavior_record cbr
LEFT JOIN behavior_rule br ON cbr.behavior_type = br.behavior_type
WHERE cbr.audit_status = 1 AND cbr.user_id = 8
GROUP BY cbr.behavior_type, cbr.behavior_name, br.unit;

-- 月度趋势
SELECT 
    DATE_FORMAT(create_time, '%Y-%m') AS month,
    COUNT(*) AS count,
    SUM(carbon_reduction) AS carbon,
    SUM(points) AS points
FROM carbon_behavior_record
WHERE audit_status = 1 AND user_id = 8
GROUP BY DATE_FORMAT(create_time, '%Y-%m')
ORDER BY month DESC;
```

## 总结

1. **问题原因**：用户ID为1的admin管理员没有行为记录
2. **解决方案**：使用有数据的用户（如admin1，user_id=8）登录测试
3. **SQL正确**：查询SQL没有问题，只是数据库中没有对应的数据
4. **返回格式**：当没有数据时，返回空数组和0值，这是正常的

## 建议

1. 前端应该处理空数据的情况，显示"暂无数据"提示
2. 测试时使用有数据的用户账号
3. 如果需要为admin添加数据，执行上面的INSERT语句
