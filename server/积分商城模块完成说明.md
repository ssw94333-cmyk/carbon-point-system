# 积分商城模块完成说明

## 已完成功能

### 商品管理
- 商品列表查询（支持分类、关键词、状态筛选）
- 商品详情查询
- 商品创建/更新/删除（管理员）
- 商品上架/下架（管理员）
- 商品图片上传

### 订单管理
- 积分兑换商品（支持实物商品和虚拟商品）
- 订单列表查询（用户查看自己的，管理员查看所有）
- 订单详情查询
- 订单取消（自动退还积分和库存）
- 订单发货（管理员）
- 订单确认收货

## 核心业务逻辑

### 兑换流程
1. 验证商品状态和库存
2. 验证用户积分和限兑数量
3. 实物商品需要收货地址
4. 扣除积分、减少库存
5. 创建订单和积分变动记录

### 取消订单
1. 只能取消待处理状态的订单
2. 自动退还积分
3. 恢复商品库存
4. 记录积分变动

## API接口

### 用户端
- `GET /api/product/list` - 商品列表
- `GET /api/product/{id}` - 商品详情
- `POST /api/order/exchange` - 兑换商品
- `GET /api/order/list` - 订单列表
- `GET /api/order/{id}` - 订单详情
- `PUT /api/order/{id}/cancel` - 取消订单
- `PUT /api/order/{id}/complete` - 确认收货

### 管理端
- `POST /api/product` - 创建商品
- `PUT /api/product/{id}` - 更新商品
- `DELETE /api/product/{id}` - 删除商品
- `PUT /api/product/{id}/status` - 上架/下架
- `PUT /api/order/{id}/ship` - 订单发货
- `POST /api/upload/product-image` - 上传商品图片

## 数据格式说明

### 分页返回格式
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "records": [],
    "total": 0,
    "page": 1,
    "size": 10
  }
}
```

### 兑换请求
```json
{
  "productId": 1,
  "quantity": 1,
  "addressId": 1,  // 实物商品必填
  "remark": "备注"
}
```

### 兑换响应
```json
{
  "orderId": 1,
  "orderNo": "EO202601180001"
}
```

## 注意事项
- 商品列表默认每页12条
- 订单列表默认每页10条
- 实物商品兑换需要收货地址
- 虚拟商品不需要收货地址
- 所有涉及积分和库存的操作都使用事务
- 管理员接口已配置权限拦截
