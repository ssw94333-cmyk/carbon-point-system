# 上传功能 404 错误快速修复

## 立即检查项

### 1. 后端服务状态
**重启后端服务**，并查看启动日志中是否有：
```
Mapped "{[/api/upload/avatar],methods=[POST]}"
Mapped "{[/api/upload/behavior-proof],methods=[POST]}"
```

如果没有看到这些映射，说明 UploadController 没有被加载。

### 2. 前端 API 地址配置
检查前端代码中的 API 基础地址：
- 应该是：`http://localhost:8080`
- 完整上传地址：`http://localhost:8080/api/upload/avatar`

### 3. 浏览器开发者工具检查
按 F12 打开开发者工具，切换到 Network 标签：
- 查看实际请求的 URL 是什么
- 状态码是 404 还是其他错误
- 请求是否真的发送到了 8080 端口

## 常见错误情况

### 情况 1：请求发送到了错误的端口
**症状**：请求 URL 是 `http://localhost:3000/api/upload/avatar`

**原因**：前端代理配置问题或 API 基础地址配置错误

**解决**：
- 检查前端的 vite.config.js 或 axios 配置
- 确保 baseURL 设置为 `http://localhost:8080`

### 情况 2：后端 Controller 未加载
**症状**：后端启动日志中没有 `/api/upload` 相关的映射

**解决**：
1. 确认 UploadController.java 已编译
2. 重新编译：`mvn clean compile`
3. 重启服务：`mvn spring-boot:run`

### 情况 3：路径拼写错误
**症状**：请求 URL 是 `/api/uploads/avatar` 或其他拼写

**解决**：
- 检查前端代码中的 API 路径
- 正确路径应该是：`/api/upload/avatar`（注意是 upload 不是 uploads）
