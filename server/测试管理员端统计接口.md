# 测试管理员端统计接口

## 测试准备

### 1. 管理员登录

```bash
curl -X POST "http://localhost:8080/api/user/login" \
  -H "Content-Type: application/json" \
  -d '{
    "username": "admin",
    "password": "123456"
  }'
```

保存返回的token。

### 2. 确认数据库中有数据

```sql
-- 查看所有用户的行为记录
SELECT 
    user_id,
    COUNT(*) as total_count,
    SUM(CASE WHEN audit_status = 1 THEN 1 ELSE 0 END) as passed_count,
    SUM(CASE WHEN audit_status = 1 THEN carbon_reduction ELSE 0 END) as total_carbon,
    SUM(CASE WHEN audit_status = 1 THEN points ELSE 0 END) as total_points
FROM carbon_behavior_record
GROUP BY user_id;
```

## 数据验证

### 1. 验证总次数

```sql
-- 管理员端：所有用户的审核通过记录
SELECT COUNT(*) as totalCount
FROM carbon_behavior_record
WHERE audit_status = 1;

-- 用户端：当前用户的审核通过记录
SELECT COUNT(*) as totalCount
FROM carbon_behavior_record
WHERE audit_status = 1 AND user_id = 8;
```

### 2. 验证总减碳量

```sql
-- 管理员端
SELECT SUM(carbon_reduction) as totalCarbon
FROM carbon_behavior_record
WHERE audit_status = 1;

-- 用户端
SELECT SUM(carbon_reduction) as totalCarbon
FROM carbon_behavior_record
WHERE audit_status = 1 AND user_id = 8;
```

### 3. 验证审核通过率

```sql
-- 管理员端
SELECT 
    COUNT(*) as total,
    SUM(CASE WHEN audit_status = 1 THEN 1 ELSE 0 END) as passed,
    ROUND(SUM(CASE WHEN audit_status = 1 THEN 1 ELSE 0 END) * 100.0 / COUNT(*), 2) as passRate
FROM carbon_behavior_record;

-- 用户端
SELECT 
    COUNT(*) as total,
    SUM(CASE WHEN audit_status = 1 THEN 1 ELSE 0 END) as passed,
    ROUND(SUM(CASE WHEN audit_status = 1 THEN 1 ELSE 0 END) * 100.0 / COUNT(*), 2) as passRate
FROM carbon_behavior_record
WHERE user_id = 8;
```

### 4. 验证各类行为统计

```sql
-- 管理员端：所有用户的行为统计
SELECT 
    cbr.behavior_type,
    cbr.behavior_name,
    br.unit,
    COUNT(*) as count,
    SUM(cbr.behavior_value) as totalValue,
    SUM(cbr.carbon_reduction) as totalCarbon,
    SUM(cbr.points) as totalPoints
FROM carbon_behavior_record cbr
LEFT JOIN behavior_rule br ON cbr.behavior_type = br.behavior_type
WHERE cbr.audit_status = 1
GROUP BY cbr.behavior_type, cbr.behavior_name, br.unit
ORDER BY count DESC;
```

## 自动化测试脚本

```bash
#!/bin/bash

echo "=== 管理员端统计接口测试 ==="

# 1. 管理员登录
echo "1. 管理员登录..."
ADMIN_LOGIN=$(curl -s -X POST "http://localhost:8080/api/user/login" \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"123456"}')

ADMIN_TOKEN=$(echo $ADMIN_LOGIN | jq -r '.data.token')
echo "管理员Token: $ADMIN_TOKEN"

# 2. 查询数据概览
echo -e "\n2. 查询数据概览..."
OVERVIEW=$(curl -s -X GET "http://localhost:8080/api/behavior/admin/statistics" \
  -H "Authorization: Bearer $ADMIN_TOKEN")

echo "数据概览："
echo $OVERVIEW | jq '.data'

TOTAL_USERS=$(echo $OVERVIEW | jq -r '.data.totalUsers')
PENDING=$(echo $OVERVIEW | jq -r '.data.pendingBehaviors')
echo "用户总数: $TOTAL_USERS, 待审核: $PENDING"

# 3. 查询行为统计（所有用户）
echo -e "\n3. 查询行为统计（所有用户）..."
ADMIN_STATS=$(curl -s -X GET "http://localhost:8080/api/behavior/admin/behavior-statistics" \
  -H "Authorization: Bearer $ADMIN_TOKEN")

echo "行为统计（所有用户）："
echo $ADMIN_STATS | jq '.data'

ADMIN_TOTAL=$(echo $ADMIN_STATS | jq -r '.data.totalCount')
ADMIN_CARBON=$(echo $ADMIN_STATS | jq -r '.data.totalCarbon')
ADMIN_POINTS=$(echo $ADMIN_STATS | jq -r '.data.totalPoints')
echo "总次数: $ADMIN_TOTAL, 总减碳: $ADMIN_CARBON, 总积分: $ADMIN_POINTS"

# 4. 普通用户登录
echo -e "\n4. 普通用户登录..."
USER_LOGIN=$(curl -s -X POST "http://localhost:8080/api/user/login" \
  -H "Content-Type: application/json" \
  -d '{"username":"admin1","password":"123456"}')

USER_TOKEN=$(echo $USER_LOGIN | jq -r '.data.token')
echo "用户Token: $USER_TOKEN"

# 5. 查询用户自己的统计
echo -e "\n5. 查询用户自己的统计..."
USER_STATS=$(curl -s -X GET "http://localhost:8080/api/behavior/statistics" \
  -H "Authorization: Bearer $USER_TOKEN")

echo "行为统计（当前用户）："
echo $USER_STATS | jq '.data'

USER_TOTAL=$(echo $USER_STATS | jq -r '.data.totalCount')
USER_CARBON=$(echo $USER_STATS | jq -r '.data.totalCarbon')
USER_POINTS=$(echo $USER_STATS | jq -r '.data.totalPoints')
echo "总次数: $USER_TOTAL, 总减碳: $USER_CARBON, 总积分: $USER_POINTS"

# 6. 对比验证
echo -e "\n6. 对比验证..."
if [ "$ADMIN_TOTAL" -ge "$USER_TOTAL" ]; then
    echo "✅ 验证通过：管理员端数据($ADMIN_TOTAL) >= 用户端数据($USER_TOTAL)"
else
    echo "❌ 验证失败：管理员端数据($ADMIN_TOTAL) < 用户端数据($USER_TOTAL)"
fi

echo -e "\n=== 测试完成 ==="
```

保存为 `test-admin-statistics.sh`，执行：
```bash
chmod +x test-admin-statistics.sh
./test-admin-statistics.sh
```

## 常见问题

### 问题1：管理员端返回的数据为空

**可能原因：**
- 数据库中没有审核通过的记录
- 日期范围过滤掉了所有数据

**解决方法：**
```sql
-- 检查是否有审核通过的记录
SELECT COUNT(*) FROM carbon_behavior_record WHERE audit_status = 1;

-- 如果没有，手动审核一些记录
UPDATE carbon_behavior_record SET audit_status = 1 WHERE id IN (11, 15, 16);
```

### 问题2：管理员端和用户端数据相同

**可能原因：**
- 数据库中只有一个用户有数据

**验证方法：**
```sql
-- 查看各用户的记录数
SELECT user_id, COUNT(*) as count
FROM carbon_behavior_record
WHERE audit_status = 1
GROUP BY user_id;
```

### 问题3：权限验证失败

**可能原因：**
- 使用的不是管理员账号
- Token过期

**解决方法：**
```sql
-- 确认用户是管理员
SELECT id, username, user_type FROM user WHERE username = 'admin';
-- user_type 应该是 1
```

- ✅ 两个接口返回格式一致
