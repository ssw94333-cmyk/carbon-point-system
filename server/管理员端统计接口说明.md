# 管理员端统计接口说明

## 概述

已添加管理员端查询所有用户数据的统计接口，与用户端接口分离。

## 接口列表

### 1. 数据概览统计（原有接口）

**接口路径：** `GET /api/behavior/admin/statistics`

**说明：** 查询系统整体数据概览

## 接口对比

### 用户端统计接口

**路径：** `GET /api/behavior/statistics`

**特点：**
- 只查询当前登录用户的数据
- 需要用户认证
- 返回个人行为统计

### 管理员端统计接口

**路径：** `GET /api/behavior/admin/behavior-statistics`

**特点：**
- 查询所有用户的数据
- 需要管理员权限
- 返回全局行为统计

## 数据说明

### 顶层统计字段

| 字段名 | 类型 | 说明 |
|--------|------|------|
| totalCount | Integer | 所有用户的总行为次数 |
| totalCarbon | Double | 所有用户的总减碳量(kg) |
| totalPoints | Integer | 所有用户的总获得积分 |
| passRate | Double | 所有用户的审核通过率(%) |

### behaviorTypeStats（各类行为统计）

| 字段名 | 类型 | 说明 |
|--------|------|------|
| behaviorName | String | 行为名称 |
| behaviorType | String | 行为类型 |
| unit | String | 单位 |
| count | Integer | 该行为的总次数（所有用户） |
| totalValue | Double | 该行为的总数值（所有用户） |
| totalCarbon | Double | 该行为的总减碳量（所有用户） |
| totalPoints | Integer | 该行为的总积分（所有用户） |
| percentage | Double | 该行为占总次数的百分比 |

### monthlyTrend（月度趋势）

| 字段名 | 类型 | 说明 |
|--------|------|------|
| month | String | 月份（yyyy-MM） |
| count | Integer | 该月所有用户的行为次数 |
| carbon | Double | 该月所有用户的减碳量 |
| points | Integer | 该月所有用户的获得积分 |

## SQL查询说明

### 用户端查询（带userId过滤）

```sql
SELECT ... 
FROM carbon_behavior_record cbr
WHERE cbr.audit_status = 1 
  AND cbr.user_id = #{userId}  -- 只查询当前用户
GROUP BY cbr.behavior_type
```

### 管理员端查询（不限用户）

```sql
SELECT ... 
FROM carbon_behavior_record cbr
WHERE cbr.audit_status = 1
  -- 不限制 user_id，查询所有用户
GROUP BY cbr.behavior_type
```

## 测试方法

### 1. 管理员登录

```bash
curl -X POST "http://localhost:8080/api/user/login" \
  -H "Content-Type: application/json" \
  -d '{
    "username": "admin",
    "password": "123456"
  }'
```

### 2. 查询数据概览

```bash
curl -X GET "http://localhost:8080/api/behavior/admin/statistics" \
  -H "Authorization: Bearer ADMIN_TOKEN"
```

### 3. 查询行为统计（所有用户）

```bash
curl -X GET "http://localhost:8080/api/behavior/admin/behavior-statistics" \
  -H "Authorization: Bearer ADMIN_TOKEN"
```

### 4. 带日期范围查询

```bash
curl -X GET "http://localhost:8080/api/behavior/admin/behavior-statistics?startTime=2026-01-01&endTime=2026-01-31" \
  -H "Authorization: Bearer ADMIN_TOKEN"
```

## 权限控制

两个接口都需要管理员权限，通过 `AdminInterceptor` 拦截器验证：

```java
@GetMapping("/admin/statistics")  // 需要管理员权限
@GetMapping("/admin/behavior-statistics")  // 需要管理员权限
```

拦截器配置：
```java
registry.addInterceptor(adminInterceptor)
    .addPathPatterns("/api/behavior/admin/**");
```

## 使用场景

### 数据概览接口
- 管理员首页展示
- 系统整体数据监控
- 用户增长趋势分析

### 行为统计接口
- 各类行为分析
- 月度趋势分析
- 行为类型占比分析
- 全局减碳量统计

## 注意事项

1. **权限验证**：两个接口都需要管理员权限
2. **数据范围**：行为统计接口查询所有用户的数据
3. **日期格式**：统一使用 yyyy-MM-dd 格式
4. **审核状态**：只统计审核通过（audit_status=1）的记录
5. **性能考虑**：数据量大时建议添加索引和缓存

## 前端调用示例

```javascript
// 查询数据概览
export const getAdminStatistics = (params) => {
  return request({
    url: '/api/behavior/admin/statistics',
    method: 'get',
    params
  })
}

// 查询行为统计（所有用户）
export const getAdminBehaviorStatistics = (params) => {
  return request({
    url: '/api/behavior/admin/behavior-statistics',
    method: 'get',
    params
  })
}

// 使用示例
async function loadStatistics() {
  // 数据概览
  const overview = await getAdminStatistics()
  console.log('数据概览:', overview.data)
  
  // 行为统计
  const behavior = await getAdminBehaviorStatistics({
    startTime: '2026-01-01',
    endTime: '2026-01-31'
  })
  console.log('行为统计:', behavior.data)
}
```

## 总结

- ✅ 管理员端可以查询所有用户的统计数据
- ✅ 用户端只能查询自己的统计数据
- ✅ 两个接口相互独立，互不影响
- ✅ 返回数据格式一致，便于前端统一处理
