### 5. 常见问题排查

#### 问题1：Token中的userId不正确

**检查方法：**
```java
// 在 BehaviorService.submitRecord 方法开始处添加日志
log.info("提交行为记录，userId: {}, dto: {}", userId, dto);
```

**解决方法：**
- 重新登录获取新的token
- 检查 UserContext.getUserId() 是否正确获取用户ID

#### 问题2：数据插入成功但查询不到

**可能原因：**
- 查询条件有问题（userId不匹配）
- 分页参数有问题
- 数据库事务未提交

**检查SQL：**
```sql
-- 直接在数据库中查询
SELECT cbr.*, u.username 
FROM carbon_behavior_record cbr
LEFT JOIN user u ON cbr.user_id = u.id
WHERE cbr.user_id = YOUR_USER_ID;
```

#### 问题3：统计数据为空

**可能原因：**
- 没有审核通过的记录（audit_status != 1）
- userId不匹配

**检查SQL：**
```sql
-- 查看用户的审核通过记录
SELECT * FROM carbon_behavior_record 
WHERE user_id = YOUR_USER_ID AND audit_status = 1;
```

#### 问题4：管理端能看到待审核数量，但列表为空

**可能原因：**
- 分页查询有问题
- 查询条件过滤掉了数据

**检查：**
```sql
-- 直接查询待审核记录
SELECT cbr.*, u.username 
FROM carbon_behavior_record cbr
LEFT JOIN user u ON cbr.user_id = u.id
WHERE cbr.audit_status = 0;
```

## 最可能的原因

根据你的描述，最可能的原因是：

1. **Token中的userId与数据库中的userId不匹配**
   - 解决：重新登录获取正确的token
   
2. **查询时使用了错误的userId**
   - 解决：检查 UserContext.getUserId() 的返回值

3. **数据库中确实没有该用户的记录**
   - 解决：直接在数据库中查询确认

4. **分页查询的问题**
   - 解决：检查 MyBatis-Plus 的分页插件配置
