# 碳行为模块快速开始指南

## 前置条件

1. ✅ JDK 17 或更高版本
2. ✅ Maven 3.6 或更高版本
3. ✅ MySQL 8.0 或更高版本
4. ✅ 已执行数据库脚本 `carbon-point-system.sql`

## 快速启动

### 1. 配置数据库

编辑 `server/src/main/resources/application.yml`：

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/carbon-point-system?useUnicode=true&characterEncoding=utf8&useSSL=false&serverTimezone=Asia/Shanghai
    username: root
    password: your_password  # 修改为你的数据库密码
```

### 2. 启动项目

```bash
cd server
mvn spring-boot:run
```

或者使用IDE（如IntelliJ IDEA）直接运行 `CarbonPointSystemApplication.java`

### 3. 验证启动

看到以下日志表示启动成功：
```
Started CarbonPointSystemApplication in X.XXX seconds
```

## 常见问题

### Q1: 启动失败，提示数据库连接错误
**A**: 检查以下几点：
1. MySQL服务是否启动
2. 数据库名称是否正确
3. 用户名密码是否正确
4. 是否已执行SQL脚本

### Q2: 接口返回401未授权
**A**: 检查以下几点：
1. 是否已登录获取token
2. token是否正确
3. token是否过期（默认24小时）
4. 请求头格式是否正确：`Authorization: Bearer {token}`

### Q3: 提交行为记录失败
**A**: 检查以下几点：
1. 行为类型是否存在
2. 行为数值是否符合规则
3. 是否需要上传证明材料
4. 是否超过每日限制

### Q4: 文件上传失败
**A**: 检查以下几点：
1. 文件格式是否支持（jpg、jpeg、png、gif）
2. 文件大小是否超过5MB
3. 项目目录是否有写权限

### Q5: 审核后积分没有增加
**A**: 检查以下几点：
1. 审核状态是否为通过（1）
2. 查看数据库user表的current_points字段
3. 查看points_change_record表是否有记录

## 调试技巧

### 1. 查看SQL日志

application.yml中已配置SQL日志输出：
```yaml
mybatis-plus:
  configuration:
    log-impl: org.apache.ibatis.logging.stdout.StdOutImpl
```

启动后可以在控制台看到执行的SQL语句。

### 2. 查看异常堆栈

全局异常处理器会打印异常堆栈，方便调试：
```java
e.printStackTrace();
```

### 3. 使用断点调试

在IDE中设置断点，可以逐步调试代码执行流程。
