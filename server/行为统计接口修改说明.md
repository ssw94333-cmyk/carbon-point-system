### 3. Mapper XML修改

**文件：** `server/src/main/resources/mapper/CarbonBehaviorRecordMapper.xml`

#### 3.1 修改 selectStatistics 查询

**新增字段：**
- `unit` - 从 behavior_rule 表获取
- `totalValue` - 行为数值总和
- `percentage` - 占比百分比

```sql
SELECT 
    cbr.behavior_type AS behaviorType,
    cbr.behavior_name AS behaviorName,
    br.unit AS unit,                              -- 新增
    COUNT(*) AS count,
    SUM(cbr.behavior_value) AS totalValue,        -- 新增
    SUM(cbr.carbon_reduction) AS totalCarbon,
    SUM(cbr.points) AS totalPoints,
    ROUND(COUNT(*) * 100.0 / (                    -- 新增：计算占比
        SELECT COUNT(*) 
        FROM carbon_behavior_record 
        WHERE audit_status = 1 AND user_id = #{userId}
    ), 2) AS percentage
FROM carbon_behavior_record cbr
LEFT JOIN behavior_rule br ON cbr.behavior_type = br.behavior_type  -- 新增JOIN
WHERE cbr.audit_status = 1 AND cbr.user_id = #{userId}
GROUP BY cbr.behavior_type, cbr.behavior_name, br.unit
ORDER BY count DESC
```

#### 3.2 新增 selectMonthlyTrend 查询

```sql
SELECT 
    DATE_FORMAT(create_time, '%Y-%m') AS month,
    COUNT(*) AS count,
    SUM(carbon_reduction) AS carbon,
    SUM(points) AS points
FROM carbon_behavior_record
WHERE audit_status = 1 AND user_id = #{userId}
GROUP BY DATE_FORMAT(create_time, '%Y-%m')
ORDER BY month DESC
LIMIT 12
```

#### 3.3 新增 countByUserId 查询

```sql
SELECT COUNT(*)
FROM carbon_behavior_record
WHERE user_id = #{userId}
```

#### 3.4 新增 countByUserIdAndStatus 查询

```sql
SELECT COUNT(*)
FROM carbon_behavior_record
WHERE user_id = #{userId} AND audit_status = #{auditStatus}
```

#### 修改后：
```java
public BehaviorStatisticsVO getStatistics(Long userId, LocalDateTime startTime, LocalDateTime endTime) {
    BehaviorStatisticsVO vo = new BehaviorStatisticsVO();
    
    // 1. 查询各类行为统计
    List<BehaviorStatisticsVO.BehaviorTypeStatistics> typeStats = 
            carbonBehaviorRecordMapper.selectStatistics(userId, startTime, endTime);
    vo.setBehaviorTypeStats(typeStats);
    
    // 2. 查询月度趋势（新增）
    List<BehaviorStatisticsVO.MonthlyTrend> monthlyTrend = 
            carbonBehaviorRecordMapper.selectMonthlyTrend(userId, startTime, endTime);
    vo.setMonthlyTrend(monthlyTrend);
    
    // 3. 计算总计
    Integer totalCount = typeStats.stream()
            .mapToInt(BehaviorStatisticsVO.BehaviorTypeStatistics::getCount)
            .sum();
    
    Double totalCarbon = typeStats.stream()
            .mapToDouble(BehaviorStatisticsVO.BehaviorTypeStatistics::getTotalCarbon)
            .sum();
    
    Integer totalPoints = typeStats.stream()
            .mapToInt(BehaviorStatisticsVO.BehaviorTypeStatistics::getTotalPoints)
            .sum();
    
    vo.setTotalCount(totalCount);
    vo.setTotalCarbon(Math.round(totalCarbon * 100.0) / 100.0);
    vo.setTotalPoints(totalPoints);
    
    // 4. 计算审核通过率（新增）
    Integer totalRecords = carbonBehaviorRecordMapper.countByUserId(userId, startTime, endTime);
    Integer passedRecords = carbonBehaviorRecordMapper.countByUserIdAndStatus(userId, 1, startTime, endTime);
    Double passRate = totalRecords > 0 ? (passedRecords * 100.0 / totalRecords) : 0.0;
    vo.setPassRate(Math.round(passRate * 100.0) / 100.0);
    
    return vo;
}
```

```java
@GetMapping("/statistics")
public Result<BehaviorStatisticsVO> getStatistics(
        @RequestParam(required = false) @DateTimeFormat(pattern = "yyyy-MM-dd") String startTime,
        @RequestParam(required = false) @DateTimeFormat(pattern = "yyyy-MM-dd") String endTime) {
    Long userId = UserContext.getUserId();
    
    // 将日期字符串转换为LocalDateTime
    LocalDateTime startDateTime = null;
    LocalDateTime endDateTime = null;
    
    if (startTime != null && !startTime.isEmpty()) {
        startDateTime = LocalDate.parse(startTime).atStartOfDay();
    }
    
    if (endTime != null && !endTime.isEmpty()) {
        endDateTime = LocalDate.parse(endTime).atTime(23, 59, 59);
    }
    
    BehaviorStatisticsVO statistics = behaviorService.getStatistics(userId, startDateTime, endDateTime);
    return Result.success(statistics);
}
```

## 新增功能

### 1. 单位字段（unit）
从 `behavior_rule` 表中获取，显示行为的单位（如"公里"、"次"、"度"）

### 2. 总数值（totalValue）
某个行为类型的所有 `behavior_value` 字段之和
- 例如：步行出行的所有公里数之和

### 3. 占比（percentage）
该行为占所有行为的百分比，保留2位小数
- 计算公式：(该行为的次数 / 所有行为的总次数) × 100

### 4. 审核通过率（passRate）
所有记录的审核通过率，保留2位小数
- 计算公式：(审核通过的记录数 / 总记录数) × 100

### 5. 月度趋势（monthlyTrend）
按月份统计的行为数据，最多返回最近12个月
- month: 月份（格式：yyyy-MM）
- count: 该月的行为次数
- carbon: 该月的减碳量
- points: 该月的获得积分

## 注意事项

1. **数据类型变化**
   - BigDecimal → Double（减碳量相关字段）
   - 新增 Double 类型的百分比字段

2. **字段名称变化**
   - totalRecords → totalCount
   - totalCarbonReduction → totalCarbon
   - typeStatistics → behaviorTypeStats
   - carbonReduction → totalCarbon
   - points → totalPoints

3. **日期参数格式**
   - 从 `yyyy-MM-dd HH:mm:ss` 改为 `yyyy-MM-dd`
   - 自动转换为当天的开始时间（00:00:00）和结束时间（23:59:59）

4. **SQL查询优化**
   - 新增 LEFT JOIN behavior_rule 获取单位
   - 使用子查询计算百分比
   - 新增月度趋势查询

## 兼容性说明

此修改会影响前端调用，需要前端同步更新：
- 修改字段名称的引用
- 处理新增的字段（unit、totalValue、percentage、passRate、monthlyTrend）
- 调整日期参数格式
