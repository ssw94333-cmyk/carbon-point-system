# 管理员用户管理接口测试指南

## 接口列表

1. `GET /api/admin/user/list` - 获取用户列表
2. `GET /api/admin/user/{id}` - 获取用户详情
3. `PUT /api/admin/user/{id}/status` - 更新用户状态
4. `PUT /api/admin/user/{id}` - 编辑用户信息
5. `PUT /api/admin/user/{id}/points` - 调整用户积分
6. `GET /api/admin/user/statistics` - 获取用户统计数据

## 数据验证 SQL

### 验证用户列表查询

```sql
-- 查询所有用户
SELECT * FROM user ORDER BY create_time DESC LIMIT 10;

-- 按用户名模糊查询
SELECT * FROM user WHERE username LIKE '%张%';

-- 按状态查询
SELECT * FROM user WHERE status = 1;
```

### 验证用户统计

```sql
-- 用户总数
SELECT COUNT(*) as totalUsers FROM user;

-- 今日新增用户
SELECT COUNT(*) as todayNewUsers 
FROM user 
WHERE DATE(create_time) = CURDATE();

-- 本月新增用户
SELECT COUNT(*) as monthNewUsers 
FROM user 
WHERE YEAR(create_time) = YEAR(NOW()) 
  AND MONTH(create_time) = MONTH(NOW());

-- 按用户类型统计
SELECT user_type, COUNT(*) as count 
FROM user 
GROUP BY user_type;

-- 按状态统计
SELECT status, COUNT(*) as count 
FROM user 
GROUP BY status;
```

### 验证积分调整

```sql
-- 查看用户积分
SELECT id, username, current_points, total_points 
FROM user 
WHERE id = 1;

-- 查看积分变动记录
SELECT * FROM points_change_record 
WHERE user_id = 1 
ORDER BY create_time DESC;
```

## 常见问题

### Q1: 返回 403 Forbidden
**原因：** 使用的不是管理员账号
**解决：** 使用管理员账号登录获取 Token

### Q2: 不能禁用自己的账号
**原因：** 系统保护机制，防止管理员误操作
**解决：** 使用其他管理员账号操作

### Q3: 邮箱已被使用
**原因：** 该邮箱已被其他用户使用
**解决：** 使用其他邮箱

### Q4: 用户积分不足
**原因：** 减少积分时，用户当前积分小于要减少的数量
**解决：** 减少较小的数量或先增加积分

### Q5: 调整数量超出范围
**原因：** 积分调整数量必须在 1-10000 之间
**解决：** 使用符合范围的数量
