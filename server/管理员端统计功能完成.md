### 2. Mapper XML - `CarbonBehaviorRecordMapper.xml`

新增SQL查询：

#### selectAdminStatistics（不限用户）
```xml
<select id="selectAdminStatistics" resultType="...">
    SELECT 
        cbr.behavior_type AS behaviorType,
        cbr.behavior_name AS behaviorName,
        br.unit AS unit,
        COUNT(*) AS count,
        SUM(cbr.behavior_value) AS totalValue,
        SUM(cbr.carbon_reduction) AS totalCarbon,
        SUM(cbr.points) AS totalPoints,
        ROUND(COUNT(*) * 100.0 / (...), 2) AS percentage
    FROM carbon_behavior_record cbr
    LEFT JOIN behavior_rule br ON cbr.behavior_type = br.behavior_type
    WHERE cbr.audit_status = 1
    -- 不限制 user_id
    GROUP BY cbr.behavior_type, cbr.behavior_name, br.unit
    ORDER BY count DESC
</select>
```

#### selectAdminMonthlyTrend（不限用户）
```xml
<select id="selectAdminMonthlyTrend" resultType="...">
    SELECT 
        DATE_FORMAT(create_time, '%Y-%m') AS month,
        COUNT(*) AS count,
        SUM(carbon_reduction) AS carbon,
        SUM(points) AS points
    FROM carbon_behavior_record
    WHERE audit_status = 1
    -- 不限制 user_id
    GROUP BY DATE_FORMAT(create_time, '%Y-%m')
    ORDER BY month DESC
    LIMIT 12
</select>
```

## 关键区别

### 用户端查询（带userId）

```sql
WHERE cbr.audit_status = 1 
  AND cbr.user_id = #{userId}  -- 只查询当前用户
```

### 管理员端查询（不限用户）

```sql
WHERE cbr.audit_status = 1
  -- 不限制 user_id，查询所有用户
```
