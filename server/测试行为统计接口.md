## 字段验证清单

### 顶层字段
- [ ] totalCount - Integer类型，总行为次数
- [ ] totalCarbon - Double类型，总减碳量
- [ ] totalPoints - Integer类型，总获得积分
- [ ] passRate - Double类型，审核通过率（百分比）
- [ ] behaviorTypeStats - 数组类型
- [ ] monthlyTrend - 数组类型

### behaviorTypeStats 数组元素
- [ ] behaviorName - String类型，行为名称
- [ ] behaviorType - String类型，行为类型
- [ ] unit - String类型，单位
- [ ] count - Integer类型，次数
- [ ] totalValue - Double类型，总数值
- [ ] totalCarbon - Double类型，总减碳量
- [ ] totalPoints - Integer类型，总积分
- [ ] percentage - Double类型，占比

### monthlyTrend 数组元素
- [ ] month - String类型，月份（yyyy-MM格式）
- [ ] count - Integer类型，该月次数
- [ ] carbon - Double类型，该月减碳量
- [ ] points - Integer类型，该月积分

## 数据计算验证

### 1. totalCount 计算
```
totalCount = SUM(behaviorTypeStats[].count)
```

### 2. totalCarbon 计算
```
totalCarbon = SUM(behaviorTypeStats[].totalCarbon)
```

### 3. totalPoints 计算
```
totalPoints = SUM(behaviorTypeStats[].totalPoints)
```

### 4. passRate 计算
```
passRate = (审核通过的记录数 / 总记录数) × 100
```

### 5. percentage 计算
```
percentage = (该行为的count / totalCount) × 100
```

### 6. totalValue 计算
```
totalValue = SUM(该行为类型的所有behavior_value)
```

## 常见问题

### 问题1：返回的数据为空

**可能原因：**
- 数据库中没有审核通过的记录
- userId不正确

**解决方法：**
```sql
-- 检查是否有审核通过的记录
SELECT * FROM carbon_behavior_record 
WHERE user_id = 2 AND audit_status = 1;

-- 如果没有，手动审核一些记录
UPDATE carbon_behavior_record 
SET audit_status = 1 
WHERE id IN (1, 2, 3);
```

### 问题2：unit字段为null

**可能原因：**
- behavior_rule 表中没有对应的行为类型

**解决方法：**
```sql
-- 检查行为规则
SELECT * FROM behavior_rule;

-- 确保每个行为类型都有对应的规则
```

### 问题3：percentage总和不等于100

**可能原因：**
- 四舍五入导致的精度问题

**说明：**
这是正常的，因为每个percentage都保留2位小数，可能会有微小的误差。

### 问题4：monthlyTrend为空

**可能原因：**
- 没有审核通过的记录
- 日期范围过滤掉了所有数据

**解决方法：**
检查数据库中的记录创建时间。

## 自动化测试脚本

```bash
#!/bin/bash

echo "=== 行为统计接口测试 ==="

# 1. 登录获取token
echo "1. 登录..."
TOKEN=$(curl -s -X POST "http://localhost:8080/api/user/login" \
  -H "Content-Type: application/json" \
  -d '{"username":"zhangsan","password":"123456"}' | jq -r '.data.token')

echo "Token: $TOKEN"

# 2. 测试不带参数
echo -e "\n2. 测试不带参数..."
RESPONSE=$(curl -s -X GET "http://localhost:8080/api/behavior/statistics" \
  -H "Authorization: Bearer $TOKEN")

echo "响应: $RESPONSE"

# 验证字段
TOTAL_COUNT=$(echo $RESPONSE | jq -r '.data.totalCount')
TOTAL_CARBON=$(echo $RESPONSE | jq -r '.data.totalCarbon')
TOTAL_POINTS=$(echo $RESPONSE | jq -r '.data.totalPoints')
PASS_RATE=$(echo $RESPONSE | jq -r '.data.passRate')

echo "总次数: $TOTAL_COUNT"
echo "总减碳: $TOTAL_CARBON"
echo "总积分: $TOTAL_POINTS"
echo "通过率: $PASS_RATE%"

# 3. 测试带日期参数
echo -e "\n3. 测试带日期参数..."
RESPONSE2=$(curl -s -X GET "http://localhost:8080/api/behavior/statistics?startTime=2024-01-01&endTime=2024-01-31" \
  -H "Authorization: Bearer $TOKEN")

echo "响应: $RESPONSE2"

# 4. 验证结果
if [ "$TOTAL_COUNT" != "null" ] && [ "$TOTAL_COUNT" != "" ]; then
    echo -e "\n✅ 测试通过！"
else
    echo -e "\n❌ 测试失败！"
fi

echo -e "\n=== 测试完成 ==="
```

保存为 `test-statistics.sh`，然后执行：
```bash
chmod +x test-statistics.sh
./test-statistics.sh
```
