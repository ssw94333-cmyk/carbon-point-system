# 行为管理查询问题修复说明

## 问题描述

用户反馈：
1. 用户端提交行为记录后没有信息
2. 我的行为和行为统计都没有数据
3. 管理端数据概览有待审核数量
4. 但是行为审核和行为记录数据都为空

## 根本原因

**缺少 MyBatis-Plus 分页插件配置**

MyBatis-Plus 的分页功能需要配置分页拦截器才能正常工作。如果没有配置，分页查询会返回空结果。

## 已修复的问题

### 1. 添加 MyBatis-Plus 分页插件配置

**文件：** `server/src/main/java/com/carbon/config/MybatisPlusConfig.java`

```java
@Configuration
public class MybatisPlusConfig {
    
    @Bean
    public MybatisPlusInterceptor mybatisPlusInterceptor() {
        MybatisPlusInterceptor interceptor = new MybatisPlusInterceptor();
        // 添加分页插件
        PaginationInnerInterceptor paginationInnerInterceptor = new PaginationInnerInterceptor(DbType.MYSQL);
        paginationInnerInterceptor.setOverflow(false);
        paginationInnerInterceptor.setMaxLimit(500L);
        interceptor.addInnerInterceptor(paginationInnerInterceptor);
        return interceptor;
    }
}
```

## 其他可能的问题

如果修复后仍然有问题，请检查以下几点：

### 1. Token问题

**症状：** 提交成功但查询不到数据

**原因：** Token中的userId与实际用户ID不匹配

**解决方法：**
```bash
# 重新登录获取新token
curl -X POST "http://localhost:8080/api/user/login" \
  -H "Content-Type: application/json" \
  -d '{
    "username": "zhangsan",
    "password": "123456"
  }'
```

### 2. 数据库问题

**症状：** 提交后数据库中没有记录

**检查方法：**
```sql
-- 查看最新的记录
SELECT * FROM carbon_behavior_record 
ORDER BY id DESC LIMIT 5;

-- 查看特定用户的记录
SELECT * FROM carbon_behavior_record 
WHERE user_id = 2;
```

### 3. 行为规则问题

**症状：** 提交时报错"行为规则不存在或已禁用"

**检查方法：**
```sql
-- 查看行为规则
SELECT * FROM behavior_rule WHERE status = 1;

-- 如果没有数据，插入测试规则
INSERT INTO behavior_rule (behavior_name, behavior_type, unit, carbon_reduction_per_unit, points_per_unit, min_value, max_value, max_points_per_day, need_proof, status, sort_order, description) VALUES
('步行出行', 'walking', '公里', 0.1200, 10, 1.00, 20.00, 200, 0, 1, 1, '步行代替开车出行');
```

### 4. 权限问题

**症状：** 管理端接口返回403或401

**检查方法：**
```sql
-- 确认用户是管理员
SELECT id, username, user_type FROM user WHERE username = 'admin';
-- user_type 应该是 1
```
