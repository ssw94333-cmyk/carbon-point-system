## 功能特性

### 核心功能
1. **行为规则管理**
   - 支持创建、更新、删除、查询行为规则
   - 规则包含减碳量、积分、限制条件等配置
   - 支持启用/禁用状态控制

2. **行为记录管理**
   - 用户提交行为记录
   - 自动计算减碳量和积分
   - 支持上传证明材料
   - 分页查询和条件筛选

3. **行为审核**
   - 管理员审核行为记录
   - 审核通过自动发放积分
   - 更新用户积分和减碳量
   - 记录积分变动历史

4. **行为统计**
   - 按行为类型统计
   - 统计次数、减碳量、积分
   - 支持时间范围筛选

5. **文件上传**
   - 支持图片上传
   - 格式和大小验证
   - 按日期组织存储

### 业务规则
1. **数值验证**
   - 最小数值限制
   - 每日最大数值限制
   - 每日最大积分限制

2. **状态控制**
   - 只能删除待审核状态的记录
   - 已使用的规则不允许删除
   - 规则启用/禁用控制

3. **权限控制**
   - 用户只能操作自己的记录
   - 管理员可以审核所有记录
   - 管理员可以管理规则

4. **事务保证**
   - 审核通过涉及多表操作使用事务
   - 保证数据一致性

## API接口列表

### 用户端接口（8个）
1. `GET /api/behavior/rules` - 获取行为规则列表
2. `GET /api/behavior/rules/{id}` - 获取行为规则详情
3. `POST /api/behavior/record` - 提交行为记录
4. `GET /api/behavior/record` - 获取行为记录列表
5. `GET /api/behavior/record/{id}` - 获取行为记录详情
6. `DELETE /api/behavior/record/{id}` - 删除行为记录
7. `GET /api/behavior/statistics` - 获取行为统计数据
8. `POST /api/behavior/upload/behavior-proof` - 上传行为证明材料

### 管理端接口（5个）
9. `GET /api/behavior/audit/list` - 获取待审核行为记录列表
10. `PUT /api/behavior/audit/{id}` - 审核行为记录
11. `POST /api/behavior/rules` - 创建行为规则
12. `PUT /api/behavior/rules/{id}` - 更新行为规则
13. `DELETE /api/behavior/rules/{id}` - 删除行为规则
