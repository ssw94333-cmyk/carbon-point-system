# 快速解决：查询为空问题

## 问题

用户ID为1（admin管理员）查询行为记录为空。

## 原因

**数据库中没有user_id=1的行为记录！**

## 快速解决方案

### 方案1：使用有数据的用户（最快）

```bash

  -H "Content-Type: application/json" \
  -d '{
    "username": "admin1",
    "password": "123456"
  }'
```

## 完整测试脚本

```bash
#!/bin/bash

echo "=== 行为管理模块测试 ==="

# 1. 使用 admin1 登录
echo "1. 登录 admin1..."
LOGIN_RESPONSE=$(curl -s -X POST "http://localhost:8080/api/user/login" \
  -H "Content-Type: application/json" \
  -d '{"username":"admin1","password":"123456"}')

TOKEN=$(echo $LOGIN_RESPONSE | jq -r '.data.token')
echo "Token: $TOKEN"

# 2. 查询行为记录
echo -e "\n2. 查询行为记录..."
RECORDS=$(curl -s -X GET "http://localhost:8080/api/behavior/record?pageNum=1&pageSize=10" \
  -H "Authorization: Bearer $TOKEN")

echo "行为记录："
echo $RECORDS | jq '.data'

# 3. 查询统计数据
echo -e "\n3. 查询统计数据..."
STATS=$(curl -s -X GET "http://localhost:8080/api/behavior/statistics" \
  -H "Authorization: Bearer $TOKEN")

echo "统计数据："
echo $STATS | jq '.data'

# 4. 提交新记录
echo -e "\n4. 提交新记录..."
SUBMIT=$(curl -s -X POST "http://localhost:8080/api/behavior/record" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "behaviorType": "walking",
    "behaviorValue": 5.5,
    "description": "测试提交"
  }')

echo "提交结果："
echo $SUBMIT | jq '.'

echo -e "\n=== 测试完成 ==="
```

保存为 `test-behavior.sh`，执行：
```bash
chmod +x test-behavior.sh
./test-behavior.sh
```
