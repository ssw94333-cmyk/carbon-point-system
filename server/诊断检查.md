# 管理端问题快速诊断

## 一键检查清单

### 1. 检查数据库

在MySQL中执行以下SQL：

```sql
-- 检查1: 确认admin用户存在且为管理员
SELECT id, username, user_type, status 
FROM user 
WHERE username = 'admin';
-- 预期结果: user_type = 1, status = 1

-- 检查2: 确认有其他用户数据
SELECT COUNT(*) as total_users FROM user;
-- 预期结果: total_users >= 7

-- 检查3: 查看所有用户
SELECT id, username, nickname, user_type, status, current_points
FROM user 
ORDER BY id;
-- 预期结果: 能看到多个用户
```

**如果admin不存在或user_type不是1**:
```sql
-- 修复admin账号
UPDATE user SET user_type = 1, status = 1 WHERE username = 'admin';
```

**如果用户数量少于7个**:
重新执行 `carbon-point-system.sql` 脚本

### 2. 测试后端接口

#### 2.1 测试登录接口

```bash
curl -X POST "http://localhost:8080/api/user/login" \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"123456"}'
```

**预期响应**:
```json
{
  "code": 200,
  "data": {
    "token": "eyJ...",
    "userInfo": {
      "userType": 1  // 必须是1
    }
  }
}
```

**保存返回的token**，用于下一步测试。

#### 2.2 测试用户列表接口

```bash
# 替换 YOUR_TOKEN 为上一步获取的token
curl -X GET "http://localhost:8080/api/user/list?page=1&size=10" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

**预期响应**:
```json
{
  "code": 200,
  "data": {
    "records": [...],  // 应该有多个用户
    "total": 7
  }
}
```

**如果返回403**:
- 检查token是否正确
- 检查是否使用admin账号登录
- 检查userType是否为1

**如果返回401**:
- 检查Authorization头格式
- 确保有"Bearer "前缀
- 重新登录获取新token

### 3. 检查后端服务

#### 3.1 确认服务已启动

```bash
# Windows
netstat -ano | findstr :8080

# 应该能看到类似输出:
# TCP    0.0.0.0:8080    0.0.0.0:0    LISTENING    12345
```

#### 3.2 查看启动日志

启动后端服务，查看控制台输出：
```
Started CarbonPointSystemApplication in X.XXX seconds
```

### 4. 使用Postman快速测试

#### 步骤1: 导入环境变量

创建环境，添加变量：
- `baseUrl`: `http://localhost:8080`
- `adminToken`: 留空（登录后自动填充）

#### 步骤2: 测试登录

**请求**:
```
POST {{baseUrl}}/api/user/login
Content-Type: application/json

{
  "username": "admin",
  "password": "123456"
}
```

**Tests脚本**（自动保存token）:
```javascript
if (pm.response.code === 200) {
    var jsonData = pm.response.json();
    pm.environment.set("adminToken", jsonData.data.token);
    console.log("✅ 登录成功，Token已保存");
    console.log("用户类型:", jsonData.data.userInfo.userType);
    
    if (jsonData.data.userInfo.userType !== 1) {
        console.error("❌ 警告: 当前用户不是管理员!");
    }
} else {
    console.error("❌ 登录失败");
}
```

#### 步骤3: 测试用户列表

**请求**:
```
GET {{baseUrl}}/api/user/list?page=1&size=10
Authorization: Bearer {{adminToken}}
```

**Tests脚本**:
```javascript
if (pm.response.code === 200) {
    var jsonData = pm.response.json();
    console.log("✅ 获取用户列表成功");
    console.log("用户总数:", jsonData.data.total);
    console.log("当前页用户数:", jsonData.data.records.length);
    
    if (jsonData.data.total === 0) {
        console.error("❌ 警告: 没有用户数据!");
    }
} else if (pm.response.code === 403) {
    console.error("❌ 权限不足，请确认使用管理员账号登录");
} else if (pm.response.code === 401) {
    console.error("❌ 未授权，请先登录");
} else {
    console.error("❌ 请求失败:", pm.response.code);
}
```

## 问题诊断决策树

```
看不到用户列表
    │
    ├─ 返回401? 
    │   └─ 是 → 检查token是否携带，格式是否正确
    │
    ├─ 返回403?
    │   └─ 是 → 检查是否使用admin账号，userType是否为1
    │
    ├─ 返回200但records为空?
    │   └─ 是 → 检查数据库是否有数据
    │
    ├─ 网络错误?
    │   └─ 是 → 检查后端服务是否启动
    │
    └─ 其他错误?
        └─ 查看后端日志和浏览器控制台
```

## 仍然无法解决？

如果以上所有检查都通过，但前端仍然看不到数据，问题可能在前端：

### 前端检查项

1. **打开浏览器开发者工具（F12）**

2. **查看Console标签**
   - 是否有JavaScript错误？
   - 是否有API调用失败的日志？

3. **查看Network标签**
   - 刷新页面
   - 查找 `/api/user/list` 请求
   - 检查请求状态码
   - 检查请求头是否有Authorization
   - 检查响应内容

4. **检查localStorage**
   - 在Console中输入：`localStorage.getItem('token')`
   - 确认token是否存在
   - 在Console中输入：`JSON.parse(localStorage.getItem('userInfo'))`
   - 确认userType是否为1

5. **检查前端路由**
   - 确认当前路由是否正确
   - 确认是否有权限验证逻辑

### 前端常见问题

**问题1**: Token未携带
```javascript
// 检查axios拦截器
axios.interceptors.request.use(config => {
  const token = localStorage.getItem('token');
  if (token) {
    config.headers.Authorization = `Bearer ${token}`;
  }
  return config;
});
```

**问题2**: API路径错误
```javascript
// 确认baseURL配置
axios.defaults.baseURL = 'http://localhost:8080';
```

**问题3**: 数据未正确渲染
```javascript
// 检查数据绑定
console.log('用户列表数据:', this.userList);
```
