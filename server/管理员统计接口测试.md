# 管理员统计接口测试指南

## 接口信息

**接口路径：** `GET /api/behavior/admin/statistics`

**权限要求：** 仅管理员可访问（需要管理员 Token）

---

## 测试步骤

### 1. 获取管理员 Token

首先使用管理员账号登录：

```bash
POST http://localhost:8080/api/user/login
Content-Type: application/json

{
  "username": "admin",
  "password": "admin123"
}
```

从响应中获取 token：
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "userType": 1
  }
}
```

### 2. 调用统计接口

使用获取的 token 调用统计接口：

```bash
GET http://localhost:8080/api/behavior/admin/statistics
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
```

### 3. 预期响应

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "totalUsers": 150,
    "activeUsers": 80,
    "todayNewUsers": 5,
    "monthNewUsers": 20,
    "totalPointsIssued": 50000,
    "totalPointsConsumed": 0,
    "totalCarbonReduction": 1250.5,
    "pendingBehaviors": 12
  }
}
```

---

## 字段说明

| 字段名 | 类型 | 说明 |
|--------|------|------|
| totalUsers | Integer | 系统中的用户总数 |
| activeUsers | Integer | 最近30天内有行为记录的用户数 |
| todayNewUsers | Integer | 今天注册的新用户数 |
| monthNewUsers | Integer | 本月注册的新用户数 |
| totalPointsIssued | Integer | 累计发放的积分总数（已审核通过） |
| totalPointsConsumed | Integer | 累计消费的积分总数（暂时为0） |
| totalCarbonReduction | Double | 累计减碳量（kg，已审核通过） |
| pendingBehaviors | Integer | 待审核的行为记录数量 |

2. 输入 URL：`http://localhost:8080/api/behavior/admin/statistics`

## 数据验证

可以通过以下 SQL 查询验证返回的数据是否正确：

```sql
-- 1. 验证用户总数
SELECT COUNT(*) as totalUsers FROM user;

-- 2. 验证活跃用户数
SELECT COUNT(DISTINCT user_id) as activeUsers 
FROM carbon_behavior_record 
WHERE create_time >= DATE_SUB(NOW(), INTERVAL 30 DAY);

-- 3. 验证今日新增用户
SELECT COUNT(*) as todayNewUsers 
FROM user 
WHERE DATE(create_time) = CURDATE();

-- 4. 验证本月新增用户
SELECT COUNT(*) as monthNewUsers 
FROM user 
WHERE YEAR(create_time) = YEAR(NOW()) 
  AND MONTH(create_time) = MONTH(NOW());

-- 5. 验证累计发放积分
SELECT COALESCE(SUM(points), 0) as totalPointsIssued 
FROM carbon_behavior_record 
WHERE audit_status = 1;

-- 6. 验证累计减碳量
SELECT COALESCE(SUM(carbon_reduction), 0) as totalCarbonReduction 
FROM carbon_behavior_record 
WHERE audit_status = 1;

-- 7. 验证待审核行为数
SELECT COUNT(*) as pendingBehaviors 
FROM carbon_behavior_record 
WHERE audit_status = 0;
```

## 常见问题

### Q1: 返回 404 Not Found
**原因：** 接口路径错误或服务未启动
**解决：** 检查 URL 是否正确，确认服务已启动

### Q2: 返回 401 Unauthorized
**原因：** 未提供 Token 或 Token 已过期
**解决：** 重新登录获取新的 Token

### Q3: 返回 403 Forbidden
**原因：** 使用的不是管理员账号
**解决：** 使用管理员账号登录获取 Token

### Q4: 某些字段返回 null
**原因：** 数据库中没有相关数据
**解决：** 这是正常情况，接口会将 null 转换为 0

## 前端集成示例

```javascript
// 在前端调用该接口
import request from '@/utils/request'

export const getAdminStatistics = () => {
  return request({
    url: '/behavior/admin/statistics',
    method: 'get'
  })
}

// 在组件中使用
const loadStatistics = async () => {
  try {
    const res = await getAdminStatistics()
    console.log('统计数据:', res.data)
    // 更新页面显示
    statsData.value = res.data
  } catch (error) {
    console.error('获取统计数据失败:', error)
  }
}
```
