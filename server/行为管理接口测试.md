# 行为管理接口测试指南

## 测试环境
- 基础URL: `http://localhost:8080`
- 需要先登录获取token

## 1. 用户端接口测试

### 1.1 获取行为规则列表
```bash
curl -X GET "http://localhost:8080/api/behavior/rules" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

### 1.2 获取行为规则详情
```bash
curl -X GET "http://localhost:8080/api/behavior/rules/1" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

### 1.3 提交行为记录
```bash
curl -X POST "http://localhost:8080/api/behavior/record" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "behaviorType": "walking",
    "behaviorValue": 5.5,
    "description": "今天步行上班",
    "proofImage": "https://example.com/proof1.jpg"
  }'
```

### 1.4 获取我的行为记录
```bash
# 基础查询
curl -X GET "http://localhost:8080/api/behavior/record?pageNum=1&pageSize=10" \
  -H "Authorization: Bearer YOUR_TOKEN"

# 带筛选条件
curl -X GET "http://localhost:8080/api/behavior/record?behaviorType=walking&auditStatus=1&pageNum=1&pageSize=10" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

### 1.5 获取行为记录详情
```bash
curl -X GET "http://localhost:8080/api/behavior/record/1" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

### 1.6 删除行为记录（仅待审核状态）
```bash
curl -X DELETE "http://localhost:8080/api/behavior/record/1" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

### 1.7 获取行为统计数据
```bash
curl -X GET "http://localhost:8080/api/behavior/statistics" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

## 2. 管理端接口测试

### 2.1 获取待审核列表
```bash
curl -X GET "http://localhost:8080/api/behavior/audit/list?pageNum=1&pageSize=10" \
  -H "Authorization: Bearer ADMIN_TOKEN"
```

### 2.2 审核行为记录（通过）
```bash
curl -X PUT "http://localhost:8080/api/behavior/audit/1" \
  -H "Authorization: Bearer ADMIN_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "auditStatus": 1,
    "auditRemark": "审核通过"
  }'
```

### 2.3 审核行为记录（拒绝）
```bash
curl -X PUT "http://localhost:8080/api/behavior/audit/2" \
  -H "Authorization: Bearer ADMIN_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "auditStatus": 2,
    "auditRemark": "证明材料不清晰，请重新上传"
  }'
```

### 2.4 获取所有行为记录（管理端）
```bash
# 基础查询
curl -X GET "http://localhost:8080/api/behavior/admin/records?pageNum=1&pageSize=10" \
  -H "Authorization: Bearer ADMIN_TOKEN"

# 带筛选条件
curl -X GET "http://localhost:8080/api/behavior/admin/records?username=zhangsan&auditStatus=1&pageNum=1&pageSize=10" \
  -H "Authorization: Bearer ADMIN_TOKEN"
```

### 2.5 创建行为规则
```bash
curl -X POST "http://localhost:8080/api/behavior/rules" \
  -H "Authorization: Bearer ADMIN_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "behaviorName": "骑行出行",
    "behaviorType": "cycling",
    "unit": "公里",
    "carbonReductionPerUnit": 0.08,
    "pointsPerUnit": 8,
    "minValue": 1.0,
    "maxValue": 100.0,
    "maxPointsPerDay": 300,
    "needProof": 1,
    "sortOrder": 2,
    "description": "骑自行车代替开车出行"
  }'
```

### 2.6 更新行为规则
```bash
curl -X PUT "http://localhost:8080/api/behavior/rules/1" \
  -H "Authorization: Bearer ADMIN_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "behaviorName": "步行出行",
    "behaviorType": "walking",
    "unit": "公里",
    "carbonReductionPerUnit": 0.142,
    "pointsPerUnit": 12,
    "minValue": 0.5,
    "maxValue": 50.0,
    "maxPointsPerDay": 250,
    "needProof": 0,
    "sortOrder": 1,
    "description": "步行代替开车出行（更新）"
  }'
```

### 2.7 删除行为规则
```bash
curl -X DELETE "http://localhost:8080/api/behavior/rules/1" \
  -H "Authorization: Bearer ADMIN_TOKEN"
```

### 2.8 获取管理员统计数据
```bash
curl -X GET "http://localhost:8080/api/behavior/admin/statistics" \
  -H "Authorization: Bearer ADMIN_TOKEN"
```

## 3. 测试场景

### 场景1：用户提交行为记录并审核
1. 用户登录获取token
2. 查询行为规则列表，选择一个规则
3. 提交行为记录
4. 管理员登录
5. 查看待审核列表
6. 审核通过该记录
7. 用户查看自己的记录，状态应为"审核通过"
8. 用户查看积分，应该增加

### 场景2：测试每日限制
1. 用户提交多条相同类型的行为记录
2. 当达到每日最大数值或积分限制时，应该提示错误

### 场景3：测试证明材料验证
1. 对于需要证明材料的行为（needProof=1）
2. 不上传图片时提交，应该提示错误
3. 上传图片后提交，应该成功

### 场景4：测试删除限制
1. 用户提交行为记录（待审核状态）
2. 删除该记录，应该成功
3. 管理员审核通过后
4. 用户尝试删除，应该提示错误

## 4. 预期响应格式

### 成功响应
```json
{
  "code": 200,
  "message": "操作成功",
  "data": { ... }
}
```

### 错误响应
```json
{
  "code": 500,
  "message": "错误信息",
  "data": null
}
```

## 5. 注意事项

1. 所有接口都需要登录认证（除了注册和登录接口）
2. 管理端接口需要管理员权限（userType=1）
3. 时间格式统一使用：`yyyy-MM-dd HH:mm:ss`
4. 审核拒绝时必须填写拒绝原因
5. 只能删除待审核状态的记录
6. 规则删除前会检查是否有关联记录
