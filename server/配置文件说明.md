# 配置文件说明

## 配置文件结构

```
src/main/resources/
├── application.yml              # 主配置文件（使用占位符）
├── application-dev.yml          # 开发环境配置
└── application-prod.yml.example # 生产环境配置模板
```

## 使用方式

### 开发环境
默认使用 `application-dev.yml` 配置，无需修改。

### 生产环境
1. 复制 `application-prod.yml.example` 为 `application-prod.yml`
2. 修改其中的配置信息
3. 启动时指定环境：`java -jar app.jar --spring.profiles.active=prod`

## 配置项说明

### 数据库配置
```yaml
spring:
  datasource:
    url: 数据库连接地址
    username: 数据库用户名
    password: 数据库密码
```

### 服务器配置
```yaml
server:
  port: 服务端口，默认8080
```

### JWT配置
```yaml
jwt:
  secret: JWT密钥，生产环境请使用复杂密钥
  expiration: Token过期时间（毫秒），默认24小时
```

### 阿里云OSS配置
```yaml
aliyun:
  oss:
    enabled: 是否启用OSS
    endpoint: OSS访问端点
    access-key-id: 访问密钥ID
    access-key-secret: 访问密钥
    bucket-name: 存储空间名称
    prefix: 文件存储目录前缀
```

## 注意事项

1. **不要提交敏感信息**：`application-prod.yml` 应添加到 `.gitignore`
2. **开发环境**：使用 `application-dev.yml`，已包含在版本控制中
3. **生产环境**：使用 `application-prod.yml`，需要手动创建并配置
4. **SQL日志**：开发环境开启，生产环境关闭
