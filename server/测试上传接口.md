# 上传接口 404 问题诊断

## 问题描述
前端调用上传接口时返回 404 错误。

## 可能的原因

### 1. 后端服务未正确启动
检查后端控制台是否有以下日志：
```
Mapped "{[/api/upload/avatar],methods=[POST]}" onto ...
```

### 2. 端口配置不匹配
- 后端配置端口：8080
- 前端请求地址应该是：`http://localhost:8080/api/upload/avatar`

### 3. Controller 未被扫描
UploadController 在 `com.carbon.controller` 包下，应该被自动扫描。

## 诊断步骤

### 1. 检查后端是否启动成功
查看控制台日志，确认：
- Spring Boot 启动成功
- 端口 8080 已监听
- Controller 映射已注册

### 2. 使用 curl 测试接口
```bash
# 先登录获取 token
curl -X POST http://localhost:8080/api/user/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"admin123"}'

# 使用 token 测试上传接口
curl -X POST http://localhost:8080/api/upload/avatar \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -F "file=@test.jpg"
```

### 3. 检查前端请求地址
打开浏览器开发者工具，查看 Network 标签：
- 请求 URL 是否正确
- 请求方法是否为 POST
- Content-Type 是否为 multipart/form-data
- Authorization header 是否存在

## 修复建议

### 如果是端口问题
检查前端的 API 基础地址配置，确保指向 `http://localhost:8080`

### 如果是认证问题
确保：
1. 用户已登录
2. Token 已保存
3. 请求头包含 Authorization: Bearer {token}

### 如果是 CORS 问题
已在 WebConfig 中配置 CORS，应该不会有问题。

## 重启步骤

1. 停止后端服务
2. 重新编译：`mvn clean compile`
3. 启动后端服务：`mvn spring-boot:run`
4. 查看启动日志，确认 UploadController 已加载
5. 测试上传功能
