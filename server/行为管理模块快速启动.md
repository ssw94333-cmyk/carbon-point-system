# 行为管理模块快速启动指南

## 1. 数据库准备

### 1.1 确认表结构
确保数据库中已创建以下表：
- `behavior_rule` - 行为规则表
- `carbon_behavior_record` - 行为记录表
- `points_change_record` - 积分变动记录表
- `user` - 用户表

如果没有，请执行项目根目录下的 `carbon-point-system.sql` 文件。

## 2. 启动服务

### 2.1 配置检查
确认 `application.yml` 中的数据库配置正确：
```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/carbon_point_system?useUnicode=true&characterEncoding=utf8&useSSL=false&serverTimezone=Asia/Shanghai
    username: root
    password: your_password
```

### 2.2 启动应用
```bash
cd server
mvn spring-boot:run
```

或者使用IDE直接运行 `CarbonPointSystemApplication.java`

### 2.3 验证启动
访问：http://localhost:8080
如果看到正常响应，说明服务启动成功。

## 3. 快速测试

### 3.1 用户登录
```bash
curl -X POST "http://localhost:8080/api/user/login" \
  -H "Content-Type: application/json" \
  -d '{
    "username": "testuser",
    "password": "123456"
  }'
```

保存返回的 token，后续请求需要使用。

### 3.2 查看行为规则
```bash
curl -X GET "http://localhost:8080/api/behavior/rules" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

### 3.3 提交行为记录
```bash
curl -X POST "http://localhost:8080/api/behavior/record" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "behaviorType": "walking",
    "behaviorValue": 5.5,
    "description": "今天步行上班"
  }'
```

### 3.4 查看我的记录
```bash
curl -X GET "http://localhost:8080/api/behavior/record?pageNum=1&pageSize=10" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

### 3.5 管理员审核（需要管理员账号）
```bash
# 先用管理员账号登录
curl -X POST "http://localhost:8080/api/user/login" \
  -H "Content-Type: application/json" \
  -d '{
    "username": "admin",
    "password": "123456"
  }'

# 查看待审核列表
curl -X GET "http://localhost:8080/api/behavior/audit/list?pageNum=1&pageSize=10" \
  -H "Authorization: Bearer ADMIN_TOKEN"

# 审核通过
curl -X PUT "http://localhost:8080/api/behavior/audit/1" \
  -H "Authorization: Bearer ADMIN_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "auditStatus": 1,
    "auditRemark": "审核通过"
  }'
```

### 3.6 查看统计数据
```bash
# 用户统计
curl -X GET "http://localhost:8080/api/behavior/statistics" \
  -H "Authorization: Bearer YOUR_TOKEN"

# 管理员统计
curl -X GET "http://localhost:8080/api/behavior/admin/statistics" \
  -H "Authorization: Bearer ADMIN_TOKEN"
```

## 5. 常见问题

### 5.1 编译错误
```bash
# 清理并重新编译
cd server
mvn clean compile
```

### 5.2 数据库连接失败
- 检查数据库是否启动
- 检查 application.yml 中的配置
- 检查数据库用户名密码是否正确

### 5.3 Token验证失败
- 确认请求头中包含 `Authorization: Bearer YOUR_TOKEN`
- 确认token没有过期
- 重新登录获取新token

### 5.4 权限不足
- 确认使用的是管理员账号（userType=1）
- 检查拦截器配置是否正确

### 5.5 审核后积分没有增加
- 检查审核状态是否为"通过"（auditStatus=1）
- 查看 points_change_record 表确认积分变动记录
- 检查事务是否正常提交
