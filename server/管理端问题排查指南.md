# 管理端问题排查指南

## 问题：登录管理端看不到其他用户信息

### 可能原因及解决方案

#### 原因1: 未使用管理员账号登录

**症状**: 
- 登录成功，但访问用户列表时返回403错误
- 提示"无权限访问，需要管理员权限"

**检查方法**:
```bash
# 1. 登录后查看用户信息
GET http://localhost:8080/api/user/info
Authorization: Bearer {你的token}

# 查看返回的userType字段
# userType = 0: 普通用户
# userType = 1: 管理员
```

**解决方法**:
使用管理员账号登录：
- 用户名: `admin`
- 密码: `123456`

#### 原因2: Token过期或无效

**症状**:
- 返回401错误
- 提示"未授权，请先登录"

**解决方法**:
1. 重新登录获取新的token
2. 确保请求头格式正确：`Authorization: Bearer {token}`
3. 注意token前面有"Bearer "前缀，且有一个空格

#### 原因3: 前端未正确调用接口

**检查方法**:
1. 打开浏览器开发者工具（F12）
2. 切换到Network标签
3. 刷新页面，查看是否有请求到 `/api/user/list`
4. 检查请求状态码和响应内容

**常见问题**:
- 请求URL错误
- 请求头未携带token
- 请求方法错误（应该是GET）

#### 原因4: 后端服务未启动或接口异常

**检查方法**:
1. 查看后端控制台是否有错误日志
2. 使用Postman直接测试接口
3. 检查数据库连接是否正常

**测试命令**:
```bash
# 使用curl测试
curl -X GET "http://localhost:8080/api/user/list" \
  -H "Authorization: Bearer {你的管理员token}"
```

#### 原因5: 数据库中没有其他用户数据

**检查方法**:
```sql
-- 查询所有用户
SELECT id, username, nickname, user_type, status 
FROM user 
ORDER BY create_time DESC;
```

**解决方法**:
如果数据库中只有admin用户，可以：
1. 注册新用户
2. 或者执行SQL脚本插入测试数据

## 完整测试流程

### 步骤1: 确认数据库有数据

```sql
-- 应该能看到至少7个用户
SELECT COUNT(*) FROM user;

-- 查看用户列表
SELECT id, username, nickname, user_type, status FROM user;
```

**预期结果**: 至少有7个用户（admin + 6个测试用户）

### 步骤2: 使用管理员账号登录

**请求**:
```bash
POST http://localhost:8080/api/user/login
Content-Type: application/json

{
  "username": "admin",
  "password": "123456"
}
```

**预期响应**:
```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiJ9...",
    "userInfo": {
      "id": 1,
      "username": "admin",
      "nickname": "系统管理员",
      "userType": 1,  // 注意这里应该是1
      "status": 1
    }
  }
}
```

**重要**: 确认 `userType` 字段为 `1`

### 步骤3: 获取用户列表

**请求**:
```bash
GET http://localhost:8080/api/user/list?page=1&size=10
Authorization: Bearer {步骤2获取的token}
```

**预期响应**:
```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "records": [
      {
        "id": 2,
        "username": "zhangsan",
        "nickname": "张三",
        "userType": 0,
        "status": 1,
        "currentPoints": 800,
        "totalPoints": 1500,
        "totalCarbonReduction": 125.50
      },
      // ... 更多用户
    ],
    "total": 7,
    "size": 10,
    "current": 1,
    "pages": 1
  }
}
```

### 步骤4: 如果仍然看不到数据

#### 4.1 检查后端日志

查看控制台输出，看是否有SQL执行日志：
```
==>  Preparing: SELECT ... FROM user WHERE ...
==> Parameters: ...
<==      Total: 7
```

#### 4.2 检查拦截器是否生效

在 `AdminInterceptor.java` 的 `preHandle` 方法中添加日志：
```java
System.out.println("当前用户类型: " + userType);
```

#### 4.3 检查Service层权限验证

在 `UserService.getUserList` 方法开始处添加日志：
```java
System.out.println("getUserList - 当前用户类型: " + UserContext.getUserType());
```

## 使用Postman测试

### 1. 创建测试集合

创建一个新的Collection，命名为"管理端测试"

### 2. 添加登录请求

**名称**: 管理员登录

**方法**: POST

**URL**: `{{baseUrl}}/api/user/login`

**Body** (raw JSON):
```json
{
  "username": "admin",
  "password": "123456"
}
```

**Tests** (自动保存token):
```javascript
if (pm.response.code === 200) {
    var jsonData = pm.response.json();
    pm.environment.set("adminToken", jsonData.data.token);
    console.log("Token已保存:", jsonData.data.token);
```

**名称**: 获取用户列表

**方法**: GET

**URL**: `{{baseUrl}}/api/user/list?page=1&size=10`

**Headers**:
```
Authorization: Bearer {{adminToken}}
```

### 4. 执行测试

1. 先执行"管理员登录"请求
2. 确认返回的userType为1
3. 再执行"获取用户列表"请求
4. 应该能看到所有用户数据

## 前端调试建议

### 1. 检查API调用

在前端代码中查找用户列表的API调用，确认：
- URL是否正确：`/api/user/list`
- 是否携带了token
- 是否正确处理了响应数据

### 2. 检查路由权限

确认管理端路由是否有权限验证：
```javascript
// 示例：Vue Router
{
  path: '/admin/users',
  component: UserList,
  meta: { requiresAdmin: true }
}
```

### 3. 检查状态管理

如果使用了Vuex或其他状态管理：
- 确认用户信息是否正确保存
- 确认userType是否正确
- 确认token是否正确存储

### 4. 检查请求拦截器

查看axios或其他HTTP库的请求拦截器：
```javascript
// 示例：axios拦截器
axios.interceptors.request.use(config => {
  const token = localStorage.getItem('token');
  if (token) {
    config.headers.Authorization = `Bearer ${token}`;
  }
  return config;
});
```

## 常见错误及解决方案

### 错误1: 403 Forbidden

**错误信息**: "无权限访问，需要管理员权限"

**原因**: 当前登录用户不是管理员

**解决**: 使用admin账号登录

### 错误2: 401 Unauthorized

**错误信息**: "未授权，请先登录"

**原因**: 
- Token未携带
- Token格式错误
- Token已过期

**解决**: 
1. 检查请求头是否有 `Authorization: Bearer {token}`
2. 重新登录获取新token

### 错误3: 返回空数组

**错误信息**: 返回200，但records为空数组

**原因**: 数据库中没有数据

**解决**: 
1. 检查数据库是否执行了初始化脚本
2. 注册一些测试用户

### 错误4: 网络错误

**错误信息**: "Network Error" 或 "ERR_CONNECTION_REFUSED"

**原因**: 后端服务未启动

**解决**: 启动后端服务
