# 快速修复：分页查询问题

## 问题

- 提交行为记录后查询不到数据
- 管理端待审核列表为空
- 统计数据为空

## 原因

**缺少 MyBatis-Plus 分页插件配置**

## 解决方案

### 方法1：重启应用（推荐）

已经添加了分页插件配置文件，只需重启应用即可：

```bash
# 停止当前运行的应用（Ctrl+C）

# 重新启动
cd server
mvn spring-boot:run
```

或者在IDE中重启应用。

### 方法2：验证配置文件

确认文件 `server/src/main/java/com/carbon/config/MybatisPlusConfig.java` 存在且内容正确：

```java
package com.carbon.config;

import com.baomidou.mybatisplus.annotation.DbType;
import com.baomidou.mybatisplus.extension.plugins.MybatisPlusInterceptor;
import com.baomidou.mybatisplus.extension.plugins.inner.PaginationInnerInterceptor;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;

@Configuration
public class MybatisPlusConfig {
    
    @Bean
    public MybatisPlusInterceptor mybatisPlusInterceptor() {
        MybatisPlusInterceptor interceptor = new MybatisPlusInterceptor();
        PaginationInnerInterceptor paginationInnerInterceptor = new PaginationInnerInterceptor(DbType.MYSQL);
        paginationInnerInterceptor.setOverflow(false);
        paginationInnerInterceptor.setMaxLimit(500L);
        interceptor.addInnerInterceptor(paginationInnerInterceptor);
        return interceptor;
    }
}
```

## 常见错误

### 错误1：返回空列表但total>0

**原因：** 分页插件未生效

**解决：** 确认MybatisPlusConfig类被Spring扫描到

### 错误2：查询报错

**原因：** SQL语法错误或表不存在

**解决：** 检查数据库表名和字段名

### 错误3：Token验证失败

**原因：** Token过期或无效

**解决：** 重新登录获取新token

## 完整测试脚本

```bash
#!/bin/bash

echo "=== 开始测试 ==="

# 1. 登录
echo "1. 用户登录..."
LOGIN_RESPONSE=$(curl -s -X POST "http://localhost:8080/api/user/login" \
  -H "Content-Type: application/json" \
  -d '{"username":"zhangsan","password":"123456"}')

echo "登录响应: $LOGIN_RESPONSE"

TOKEN=$(echo $LOGIN_RESPONSE | jq -r '.data.token')
echo "Token: $TOKEN"

# 2. 提交行为记录
echo -e "\n2. 提交行为记录..."
SUBMIT_RESPONSE=$(curl -s -X POST "http://localhost:8080/api/behavior/record" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "behaviorType": "walking",
    "behaviorValue": 5.5,
    "description": "测试提交"
  }')

echo "提交响应: $SUBMIT_RESPONSE"

# 3. 查询记录
echo -e "\n3. 查询行为记录..."
QUERY_RESPONSE=$(curl -s -X GET "http://localhost:8080/api/behavior/record?pageNum=1&pageSize=10" \
  -H "Authorization: Bearer $TOKEN")

echo "查询响应: $QUERY_RESPONSE"

# 4. 检查结果
TOTAL=$(echo $QUERY_RESPONSE | jq -r '.data.total')
echo -e "\n总记录数: $TOTAL"

if [ "$TOTAL" -gt 0 ]; then
    echo "✅ 测试通过！查询到 $TOTAL 条记录"
else
    echo "❌ 测试失败！没有查询到记录"
fi

echo -e "\n=== 测试完成 ==="
```

保存为 `test.sh`，然后执行：
```bash
chmod +x test.sh
./test.sh
```
